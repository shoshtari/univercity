\lr{\section{LDA}}
اگر در عبارت 
$
\sum\limits_{j = 1}^{n_2} (y_i - y_j)^2
$
مقدار 
$y_i$
برابر با میانگین باشد، حاصل جمع برابر با همان 
$s_2$
می‌شود. حال اگر در نظر بگیریم که 
$y_i = m_2 + \delta_i$
داریم:
\begin{latin}
	~\\
	$
	\sum\limits_{j = 1}^{n_2} (y_i - y_j)^2 = \sum\limits_{j = 1}^{n_2} (y_j - m_2 - \delta_i)^2
	 = 
	 \sum\limits_{j = 1}^{n_2} ((y_j - m_2) ^2 + \delta_i^2 - 2\delta_i (y_j - m_2) )
	 \\
	 = 
	 s_2^2 + n_2 \delta_i^2 + 0 = s_2^2 + n_2 \delta_i
	$
\end{latin}

(چون حاصل جمع تفاوت $y_2$ از $m_2$ صفر می‌شود، عبارت سوم صفر شد.)

پس مقدار $J$ برابر است با:
\begin{latin}
	~\\
	$
	J = \cfrac{1}{n_1 n_2} 	\sum\limits_{i = 1}^{n_1}  	\sum\limits_{j = 1}^{n_2} (y_1 - y_2)^2 
	=   \cfrac{1}{n_1 n_2} 	\sum\limits_{i = 1}^{n_1}  (s_2^2 + n_2 \delta_i^2)
	\\
	= \cfrac{1}{n_1 n_2} 	\sum\limits_{i = 1}^{n_1}  (s_2^2 + n_2 (y_i - m_2)^2)
	= \cfrac{s_2^2}{n_2} + \cfrac{1}{n_1} \sum\limits_{i = 1}^{n_1}  (y_i - m_2)^2
	\\
	= \cfrac{s_2^2}{n_2} + \cfrac{1}{n_1} \sum\limits_{i = 1}^{n_1}  (y_i - m_1 + m_1 - m_2)^2
	\\
	= \cfrac{s_2^2}{n_2} + \cfrac{1}{n_1} \sum\limits_{i = 1}^{n_1}  ((y_1 - m_1)^2 + (m_1 - m_2)^2 + 2(y_i - m_1)(_m1-m_2))
	\\
	= \cfrac{s_2^2}{n_2} + \cfrac{s_1^2}{n_1} +  (m_1 - m_2)^2
	$
\end{latin}
که این همان عبارت صورت سوال است.

\lr{\subsection{PCA}}
اگر با یک تبدیل خطی بخواهیم داده‌ها بیشترین پراکندگی را از هم داشته باشند داریم:
\begin{latin}
	~\\
	$
	y_i = w^T x_i  \quad w^T w = I \quad
	v = \cfrac{1}{n} \sum\limits_{i = 1}^n (y_i - \bar{y})^2 
	$
\end{latin}	
چون 
$x$
ها میانگین صفر دارند، میانگین 
$y$
نیز صفر است (زیرا ترکیب خطی است). پس یعنی هدف بیشینه کردن مقدار 
$v  = \cfrac{1}{n} \sum\limits_{i = 1}^n (y_i)^2 $
است. پس داریم:
\begin{latin}
	~\\
	$
	v = \sum\limits_{i = 1}^n (y_i )^2  = \sum\limits_{i = 1}^n (w^T x_i )^2
	= \sum\limits_{i = 1}^n (w^T x_i) (x_i^T w) =\cfrac{1}{n}  w^T (\sum\limits_{i = 1}^n (x_i x_i^T)) w
	= \cfrac{1}{n}  w^T nS w = w^T S w
	$
\end{latin}
(چون میانگین صفر است، ماتریس کواریانس همان جمع ضرب ها شد)

حال نیاز است تا مقداری برای 
$w$ 
انتخاب شود تا این عبارت را بیشینه کند(اگر شرط اندازه برای وزن‌ها نباشد، صرفا می‌توان وزن‌های بسیار بزرگ انتخاب کرد و به واریانس‌های زیاد رسید). اگر از شیوه لاگرانژین استفاده کنیم داریم:
\begin{latin}
	~\\
	$
	L = w^T S w - \lambda (ww^T - 1) \xrightarrow{derviative to w}
	\cfrac{\partial L}{\partial w} = 2Sw - 2\lambda w = 0 \Rightarrow S w = \lambda w
	$
\end{latin}
