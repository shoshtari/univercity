# UniPick

A smart course selection assistant for universities using the Golestan Student Information System.

## Overview

UniPick helps students make informed decisions when selecting courses for their semesters. It simplifies the often complex and time-consuming process of choosing courses in universities that use Golestan (گلستان), providing valuable insights and tools to optimize your academic schedule.

## Problem Statement

Students face several challenges when selecting courses in Golestan:

- **Time conflicts**: Manually checking for schedule conflicts between courses
- **Prerequisites**: Tracking which courses you're eligible to take
- **Course planning**: Optimizing course selection across multiple semesters
- **Limited information**: Difficulty accessing comprehensive course details and instructor information
- **Registration rush**: Last-minute decision making during the hectic registration period

## Features

- 🗓️ **Schedule Visualization**: See your weekly schedule with all selected courses
- ⚠️ **Conflict Detection**: Automatically detect time conflicts between courses
- 🔍 **Course Search**: Easily search and filter available courses
